SM BUILDERS & CONSTRUCTION — ওয়েবসাইট ফাইল

ফাইল:
- index.html: সম্পূর্ণ responsive ওয়েবসাইট

প্রকাশের আগে অবশ্যই যাচাই করুন:
1. ফোন, WhatsApp, ইমেইল এবং তিনটি অফিসের ঠিকানা সঠিক কি না।
2. ওয়েবসাইটে প্রদর্শিত সব সেবা বাস্তবে দিতে পারবেন কি না।
3. ছবিগুলো উদাহরণমূলক; নিজের প্রজেক্টের ছবি হলে পরে প্রতিস্থাপন করুন।
4. আপনার অনুমতি ছাড়া কোনো ভুয়া রিভিউ বা সম্পন্ন প্রজেক্ট যোগ করা হয়নি।

GitHub Pages-এ বিনামূল্যে প্রকাশের সংক্ষিপ্ত ধাপ:
1. GitHub.com-এ অ্যাকাউন্ট খুলুন/লগইন করুন।
2. New repository তৈরি করুন; নাম দিন sm-builders-website এবং Public নির্বাচন করুন।
3. Add file > Upload files দিয়ে index.html আপলোড করে Commit changes চাপুন।
4. Repository Settings > Pages-এ যান।
5. Build and deployment অংশে Deploy from a branch নির্বাচন করুন; Branch: main, Folder: /(root) দিয়ে Save করুন।
6. প্রকাশিত URL দেখা গেলে সেটি খুলে মোবাইলে পরীক্ষা করুন।
7. Google Search Console-এ (search.google.com/search-console) যান। URL prefix হিসেবে প্রকাশিত সাইটের URL যোগ করুন।
8. যাচাইকরণের নির্দেশনা অনুসরণ করুন। পরে URL Inspection দিয়ে হোমপেজ পরীক্ষা করে Request indexing চাপুন।
9. Google-এ দেখা দিতে সময় লাগতে পারে; indexing নিশ্চিত নয়।

নোট:
- GitHub Pages-এ সাধারণত URL হবে https://YOUR-USERNAME.github.io/sm-builders-website/ — YOUR-USERNAME আপনার GitHub username দিয়ে প্রতিস্থাপন হবে।
- নিজস্ব ডোমেইন এখনই কেনা বাধ্যতামূলক নয়।
- Google Business Profile তৈরি করার সময় বাস্তব, যোগ্য ব্যবসার তথ্য ব্যবহার করুন। ভুয়া অফিস/ঠিকানা যোগ করবেন না।
